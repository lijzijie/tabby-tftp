# Security policy

## Scope

This plugin implements unauthenticated TFTP. TFTP traffic is unencrypted and the local server is intended for trusted, isolated networks only.

The server is read-only and restricts requests to regular files below its configured root directory. This is not a replacement for network access controls or firewall rules.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Once the GitHub repository is created, use its private security advisory flow or contact the maintainer privately with reproduction steps, affected version, and environment details.
