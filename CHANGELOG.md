# Changelog

All notable changes to this project are documented here.

## [0.2.1] - 2026-08-11

- Keep the firmware TFTP server alive when its management window is closed.
- Persist server settings, including the selected root directory.
- Make automatic server shutdown opt-in.
- Add a shared server state and clearer serial-console workflow.

## [0.2.0]

- Add a local read-only TFTP server with MobaXterm-style controls.
- Add bind-address selection, local IPv4 discovery, logs, notifications, and auto-stop.

## [0.1.0]

- Initial Tabby TFTP client with upload/download support.
